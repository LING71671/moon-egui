较 LeaferJS 节省 95% 内存开销
JavaScript 对象在 V8 引擎中附带沉重的 Hidden Class 原型链与字典元数据（LeaferJS 占用约 320~350MB，Fabric.js 超过 2.5GB）。MoonBit 的紧凑定长平铺结构将 1,000,000 节点内存牢牢压在 18MB 以内。
堆内存消耗: ~18 MB vs 320 MB
O(1) 微秒级视窗空间数学裁剪
相机平移缩放时，通过逆矩阵反投影在 0.03ms 内瞬间算出屏幕可视区间，无需遍历任何不可见节点，直接过滤掉 99.8% 的无效渲染开销。
裁剪开销: < 0.05 ms / 帧
零 GC 抖动无限画布平移缩放
连续鼠标拖拽与滚轮漫游 1,000,000 个实体，单帧产生 0 字节动态堆垃圾。帧内内存全量复用，杜绝 V8 Major GC 停顿掉帧，稳锁 60 FPS。
帧时间余量: > 98%
