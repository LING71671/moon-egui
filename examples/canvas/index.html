工程级架构设计，突破 Web 图形极限

为大规模图形交互、CAD 工业制图与复杂界面打造的即时模式基础设施

⚡

纯粹即时模式 (Immediate Mode)

无多层虚拟 DOM 树，无状态同步漂移。一帧即是一切，代码直观声明，状态与渲染完全解耦统一。

🛡️

零 GC 内存损耗 (Zero GC Overhead)

MoonBit 编译为原生紧凑 WebAssembly，内存常驻仅 ~18MB，彻底杜绝复杂高频场景下的 JavaScript GC 停顿与卡顿。

📐

CAD 双轴标尺与微米投影

内置 50px 到 100,000px 的自适应双轴刻度标尺，支持被选中物体的空间坐标动态投影高亮。

🌌

O(1) 空间局部性与视口剔除

内置高效空间索引与自适应 LOD 采样算法，百万空间实体仅绘制视口可见区域，内核耗时低于 0.25ms。

🎨

统一 DrawCmd 指令流抽象

渲染管线与宿主环境解耦，无缝对接 HTML Canvas2D、WebGL、WebGPU 以及桌面端原生渲染后端。

🔒

强类型安全与高可靠性

充分发挥 MoonBit 现代类型系统优势，编译期排查一切空指针与内存隐患，构建稳如磐石的工业级图形应用。

简洁优雅的即时模式语法

两分钟上手，用 MoonBit 声明式编写高性能图形界面：

/// 即时模式更新循环：每一帧直接描述 UI 结构与交互 pub fn render_editor(ctx : @core.UIContext) -> @draw.DrawList { ctx.begin_frame(input) // 声明按钮与响应 if ui.button("触发冲击波").clicked() { state.shockwave_active = true } // 声明空间实体与视口检测 for item in visible_items { ui.draw_cup(item.pos, item.color) } ctx.end_frame() ctx.draw_list() }
