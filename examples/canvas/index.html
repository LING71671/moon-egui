设计特点

专注于简洁、模块化与易集成的即时模式 GUI 基础组件

即时模式 (Immediate Mode)

无需维护复杂的组件状态机，逐帧根据当前数据直接描述界面逻辑，轻量直观。

轻量与零额外依赖

纯 MoonBit 代码编写，无臃肿第三方前端框架依赖，打包产物紧凑。

CAD 双轴刻度标尺

内置平移缩放自适应标尺与坐标读数，方便进行空间测距与定位观察。

视口裁剪与自适应绘制

仅计算与绘制视口内的可见方块，保证交互平移缩放时的平稳流畅。

解耦的图元指令流

DrawCmd 指令流与宿主环境解耦，便于对接 Canvas2D、WebGL 或本地图形库。

静态类型安全

借助 MoonBit 现代类型系统与模式匹配，减少运行时潜在异常。

简洁优雅的即时模式语法

两分钟上手，用 MoonBit 声明式编写高性能图形界面：

/// 即时模式更新循环：每一帧直接描述 UI 结构与交互 pub fn render_editor(ctx : @core.UIContext) -> @draw.DrawList { ctx.begin_frame(input) // 声明按钮与响应 if ui.button("触发冲击波").clicked() { state.shockwave_active = true } // 声明空间实体与视口检测 for item in visible_items { ui.draw_cup(item.pos, item.color) } ctx.end_frame() ctx.draw_list() }
