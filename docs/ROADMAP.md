### 第二阶段规划：专业工程能力深度演进（9月12日 – 9月25日）

### 里程碑 5：专业桌面交互与输入系统完善（9月12日 – 9月15日）

* **核心目标**：向专业桌面软件的交互标准看齐，完善除基础点击外的键盘流转与上下文操作能力。
* **交付清单**：
  - [x] **全局命令面板原型 (`CommandPalette` / `⌘K`)** [已交付]：快捷指令模糊检索、历史记录与键盘导航动作派发；
  - [x] **上下文右键菜单与级联菜单 (`ContextMenu` / `SubMenu`)** [已交付]：就地弹出操作菜单，支持多层级悬停展开与边缘边界自适应翻转；
  - [x] **多行文本与轻量代码编辑 (`CodeEditor`)** [已交付]：支持基础多行排版、行号指示栏、光标选区与剪贴板协同；
  - [x] **分层资产树控件 (`TreeView` / `TreeNode`)** [已交付]：多层级折叠展开记忆、缩进引导线与单选/多选状态维护；
  - [x] **工程数值调节器：环形旋钮 (`Knob`)** [已交付]：270° 圆弧物理行程、单极/双极顺滑填充、垂直位移拖拽与 Alt+Click 快速复位；
  - [x] **官网组件展厅 100% 原生 Canvas 引擎重构** [已交付]：全面接入纯 MoonBit 编译的 WebAssembly/Canvas 即时渲染管线，零仿真 DOM 与 CSS，货真价实；
  - [x] **推子调节器 (`Fader`)** [已交付]：线性音量/参数推子通道，支持双侧刻度标尺、垂直拖拽位移、滚轮微调与 Alt+Click 复位（里程碑 5 达成 100% 交付）；
* **验收标准**：
  - 核心输入组件支持纯键盘操作顺畅穿梭，无头交互测试覆盖率稳步提升（达成 167/167 项测试通过）。

---

### 里程碑 6：工作台排版体系与视窗停靠探索（9月16日 – 9月18日）

* **核心目标**：从单视窗与简单流式排版，拓展至支持多视口自由划分的工作台布局能力。
* **交付清单**：
  - [x] **可嵌套弹性分栏器 (`SplitPane` / `splitter.mbt`)** [已交付]：支持横向与纵向视口分割，拖拽中缝发丝线按比例缩放左右/上下区域，并设边界约束；
  - [x] **多视窗磁吸与停靠排版系统 (`DockArea` / `dock.mbt`)** [已交付]：基于递归 DockTree 的工作台排版，支持分栏拖拽缩放、标签页切换关闭与局部 Scissor 剪裁保护；
  - [ ] **动量物理与阻尼动效 (`Spring Physics`)**：为视窗拖拽、滚动停靠引入平滑可控的物理衰减，提升操控细腻度。
* **验收标准**：
  - 视窗可在工作台区域内灵活拖拽停靠，分割面板支持多级嵌套且尺寸比例稳定持久化（达成 195/195 项测试通过）。

---

### 里程碑 7：数据密集型组件与可视化探索（9月19日 – 9月21日）

* **核心目标**：验证在大量工程数据与节点拓扑场景下的渲染效率与可用性。
* **交付清单**：
  - [ ] **虚拟化数据表格 (`VirtualTable`)**：利用即时视口裁剪，承载大量行数据时每帧仅计算并光栅化可见部分，支持列宽调节与点击排序；
  - [ ] **节点流连线编辑器原型 (`NodeEditor`)**：支持无极画布中的节点卡片拖拽、端口（Port）连线判定与自适应三次贝塞尔平滑连接线；
  - [x] **基础工程图表套件 (`Plot` / `Sparkline`)** [已交付]：支持折线 (Line)、散点 (Scatter)、面积 (Area) 多系列混排与柱状统计图 (`BarChart`) 绘制，支持网格辅助线、双轴数值刻度、准心十字光标与悬停数据浮窗；
  - [ ] **几何矢量 SVG 导出器 (`SvgExporter`)**：支持将当前渲染管线图元序列无损导出为标准 `.svg` 矢量文件。
* **验收标准**：
  - 在大量数据行与多节点拓扑连线场景下维持 60 FPS 稳定帧率，无明显内存抖动。

---

### 里程碑 8：高性能渲染管线探索与典型场景范例（9月22日 – 9月24日）

* **核心目标**：探索硬件加速图形管线可行性，并提供多个贴近实际工程应用的参考范例。
* **交付清单**：
  - [ ] **WebGL 2.0 顶点合批渲染后端探索**：探索在 Wasm 内存中直接组织顶点与索引缓冲（Vertex / Index Buffer），验证将 Canvas 2D 调用合批为单次 GPU 绘制的性能表现；
  - [ ] **典型应用参考范例整合（上线官网展厅）**：
    - CAD 工程向量绘图板范例（完善标尺、吸附、属性面板交互）；
    - 节点蓝图逻辑流范例；
    - 简易数字音频/波形工作台原型；
    - 轻量在线代码工作区原型。
* **验收标准**：
  - 各参考范例在官网展厅流畅运行，架构与组件调用直观规范。

---

## 2. 后续演进与技术探索 (Future Work)

- **多后端持续打磨**：深化 WebGL / WebGPU 批量绘制管线与着色器特效；
- **跨平台原生后端接入**：结合 MoonBit 原生编译能力，探索对接桌面原生图形后端（如 Raylib / SDL3）；
- **高级复杂图元生态**：持续扩充工业自动化、算法可视化与科学计算等垂直领域的即时模式组件。
