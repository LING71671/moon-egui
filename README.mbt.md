# moon-egui

High-performance, pure MoonBit Immediate-Mode GUI library for WebAssembly, Canvas, and Games.

## Overview

`moon-egui` is an Immediate-Mode GUI (IMGUI) engine native to the MoonBit ecosystem. Inspired by Rust's `egui` and C++'s `Dear ImGui`, it brings effortless, declarative 60-FPS reactive UI development to WebAssembly and HTML5 Canvas with zero DOM overhead and zero external dependencies.

## Key Features

- **Pure MoonBit Core**: 100% pure MoonBit logic, render-agnostic, headless.
- **Ultra Lightweight**: Minimal binary footprint (<50 KB target).
- **Desktop Layout System**: Menu bars, side panels, multi-column layouts, and draggable floating windows.
- **Rich Widget Suite**: Buttons, labels, sliders, Blender-style `DragValue` number scrubbers, checkboxes, and sparkline plots.
- **Custom Painter API**: Built-in 2D drawing primitives (circles, bezier curves, lines, polygons).
